Superstore Sales Analysis Dashboard | Power BI

📌 Project Overview

This project is an interactive Superstore Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales performance, profit, orders, customers, product categories, regions, and product-wise sales.

The objective is to transform raw sales data into meaningful business insights through interactive visualizations.

🛠️ Tools & Technologies

Microsoft Power BI

Superstore Sales Dataset

Data Analysis

Data Visualization

📈 Key Performance Indicators (KPIs)

The dashboard highlights five important KPIs:

Total Sales: 117.30K

Total Orders: 278

Total Profit: 6.77K

Total Customers: 239

Profit Margin: 0.06

📊 Dashboard Features

1. Category-Wise Sales Analysis

Analyzes total sales across three product categories:

Furniture

Office Supplies

Technology

2. Sales Trend Analysis

Visualizes sales based on order dates to understand sales trends over time.

3. Region-Wise Sales Analysis

Provides insights into sales distribution across:

Central

East

South

West

4. Product-Wise Sales Analysis

Displays sales performance across different products and helps identify top-selling products.

5. Interactive Filters

The dashboard includes slicers for:

Category

Region

Users can interact with these filters to explore sales data.
